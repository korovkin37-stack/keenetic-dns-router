# Изменения

[English](CHANGELOG.md) · **Русский**

## 5.38.1
- Переведены многострочные подсказки (в том числе у проверки DPI) и многострочные пояснения в результатах проверки.
- Изменения релиза в панели показываются на языке интерфейса.
- Описание репозитория на английском, описание релиза собирается из CHANGELOG.

## 5.38.0
- Обновления с GitHub: «Настройки → Обновление панели» показывает новый релиз и его изменения, скачивает архив и ставит его с той же проверкой и откатом; значок версии подсвечивается, когда вышла новая.

## 5.37.0
- Проверка DPI: удаление прогонов по одному и всех сразу.

## 5.36
- «Белые SNI»: итог «лучшие имена» с раскрытием, где имя прошло и где нет; тест обрыва всегда включается вместе с «Белыми SNI».

## 5.35
- QUIC в проверке доменов: свой Initial-пакет на PHP, вердикты OK / CLOSED / TIMEOUT, проверка через туннель (модуль sockets).
- Таблицы проверки заполняются по ходу прогона; единый порядок тестов.
- Проверка системы: модули PHP проверяются через `extension_loaded()`, кнопки установки обновляют ядро PHP вместе с модулем.

## 5.34
- Тест маршрута: реальный запрос curl через интерфейс маршрута, свой SNI, выбор из «белых» имён, детали по строкам.

## 5.31–5.33
- Редактируемые списки проверки DPI, свой SNI для теста хостингов, «Белые SNI» таблицей по AS.
- Сертификаты в проверке доменов: что реально отдаёт сервер, отличие «чужое имя» от «недоверенный».
- DNS: маршрут каждого запроса, коды ответа (NXDOMAIN, NODATA, SERVFAIL).

## 5.29–5.30
- Проверка DPI (по мотивам dpi-detector) и вкладка «Диагностика».

## 5.28
- Клиенты: регистрация и политика через RCI.

## 5.24–5.27
- Диспетчер задач с очередью и паузой, правки без блокировки, компактные «Настройки» и «Сервис», сортировка и фильтр клиентов, восстановление правила BGP после применения маршрутов.
