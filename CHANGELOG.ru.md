# Изменения

[English](CHANGELOG.md) · **Русский**

## 5.40.0
Второй раунд аудита.
- Маршруты применяются без провала: новые пишутся поверх старых, потом удаляются лишние; таблицы больше не очищаются, трафик цели не теряет маршрут ни на миг. Два вызова от root вместо десятков.
- bird4.conf проверяется `bird -p` до сохранения; конфиг, который bird не принял, не записывается. Включение лога bird больше не принимает «No syntax errors» за ошибку.
- Прогоны DPI хранятся в базе, а не в папке `dpi/` (старые переносятся сами).
- Загрузки (списки, GitHub): не больше 20 МБ, только http(s), редиректы только на https; источник списков не может указывать на сам роутер.
- Метки политик из Keenetic принимаются только как hex, прежде чем попасть в `ip rule` и хук bird.
- Не больше 100 политик (таблица списков на 100 выше таблицы политики).
- Импорт целей — одна транзакция: всё или ничего, и намного быстрее.
- Правка, удаление и обновление несуществующей цели сообщают об этом; `enabled` читается как логическое.
- Список с доменами больше 1000 сообщает, что остальные не разрешались; списки читаются построчно.
- В тесте DNS не больше 8 серверов, одновременно не больше двух тестов; curl в тесте маршрута идёт по очереди.
- Пока заменяются файлы панели, остальные запросы ждут (503), а не попадают на смесь старого и нового кода.
- Окна: Tab не выходит из окна, страница под ним не прокручивается, фокус возвращается после закрытия; крестик — кнопка.
- Окна с деталями игнорируют запоздавшие ответы на прошлый запрос.

## 5.39.0
Харденинг по итогам аудита.
- В панели больше нет inline-обработчиков кликов; Content-Security-Policy запрещает чужие скрипты.
- Пароль для `su` передаётся через stdin и не виден в списке процессов.
- Изменяющие действия принимаются только JSON POST-запросом (защита от межсайтовых запросов).
- 5 неверных паролей с одного адреса блокируют вход на 5 минут.
- Обновление с GitHub: архив сверяется с sha256 от GitHub, более старая или та же версия не ставится.
- Запросы к RCI ограничены 15 с; пустой список политик от Keenetic больше не стирает политики в панели.
- Списки пропускают также 100.64/10, 172.16/12, 198.18/15 и документационные сети.
- Статический маршрут шире /8 (в том числе 0.0.0.0/0) требует подтверждения.
- Таблицы целей и политик рисуются быстрее; сортировка по текущему IP числовая; сообщение о лимите DNS говорит про 8.
- nginx (новая установка): заголовки `nosniff` и `X-Frame-Options`, папка `dpi/` закрыта. На существующей установке добавьте `dpi/.*` в `location`, который прячет `config.php`.

## 5.38.1
- Переведены многострочные подсказки (в том числе у проверки DPI) и многострочные пояснения в результатах проверки.
- Изменения релиза в панели показываются на языке интерфейса.
- Описание репозитория на английском, описание релиза собирается из CHANGELOG.

## 5.38.0
- Обновления с GitHub: «Настройки → Обновление панели» показывает новый релиз и его изменения, скачивает архив и ставит его с той же проверкой и откатом; значок версии подсвечивается, когда вышла новая.

## 5.37.0
- Проверка DPI: удаление прогонов по одному и всех сразу.

## 5.36
- «Белые SNI»: итог «лучшие имена» с раскрытием, где имя прошло и где нет; тест обрыва всегда включается вместе с «Белыми SNI».

## 5.35
- QUIC в проверке доменов: свой Initial-пакет на PHP, вердикты OK / CLOSED / TIMEOUT, проверка через туннель (модуль sockets).
- Таблицы проверки заполняются по ходу прогона; единый порядок тестов.
- Проверка системы: модули PHP проверяются через `extension_loaded()`, кнопки установки обновляют ядро PHP вместе с модулем.

## 5.34
- Тест маршрута: реальный запрос curl через интерфейс маршрута, свой SNI, выбор из «белых» имён, детали по строкам.

## 5.31–5.33
- Редактируемые списки проверки DPI, свой SNI для теста хостингов, «Белые SNI» таблицей по AS.
- Сертификаты в проверке доменов: что реально отдаёт сервер, отличие «чужое имя» от «недоверенный».
- DNS: маршрут каждого запроса, коды ответа (NXDOMAIN, NODATA, SERVFAIL).

## 5.29–5.30
- Проверка DPI (по мотивам dpi-detector) и вкладка «Диагностика».

## 5.28
- Клиенты: регистрация и политика через RCI.

## 5.24–5.27
- Диспетчер задач с очередью и паузой, правки без блокировки, компактные «Настройки» и «Сервис», сортировка и фильтр клиентов, восстановление правила BGP после применения маршрутов.
